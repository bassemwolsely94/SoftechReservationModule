## Tests added

- `apps/tests/test_sort_ordering_security.py` — unknown / hidden / injection sort keys: `explicit_order_by` → 400; the grid filter and `ORDERING_KEYS` views ignore them (default order — no sort oracle); sweep: no view orders by `'__all__'` or a secret-looking column.
  *Deviation from the plan text:* the grid filter **ignores** an unknown key instead of answering 400. That is the existing, deliberate «unknown value = default» rule; ignoring gives the same protection (the key has no effect) without breaking a grid on a stale key. Making it 400 is a one-line change if the owner prefers.
- `test_wildcard_search.py` — `_` and `\` literal everywhere; `%` literal in the exact-text tier (it is a wildcard in the pattern tiers by the owner decision of 2026-10-05, which the plan's wording conflicts with); quotes/semicolons are text.
